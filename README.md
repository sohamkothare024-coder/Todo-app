# 📝 To-Do App

A simple and responsive **To-Do List Web Application** built using **HTML and CSS**. The project provides a clean interface for managing daily tasks.

## 📌 Project Overview

The To-Do App is a beginner-friendly web project created to practice frontend development concepts using HTML and CSS.

The application focuses on creating a clean and simple user interface for adding and managing daily tasks.

## ✨ Features

* ➕ Add tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📋 View task list
* 🎨 Clean and simple user interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
